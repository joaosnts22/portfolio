# Portfólio · João Pedro dos Santos Fonseca

Site pessoal com meus projetos, stack e contato.

- HTML, CSS e JavaScript puros, sem build e sem dependências
- Tema claro/escuro (segue o sistema, com botão para alternar)
- Português e inglês (botão PT/EN; segue o idioma do navegador)
- Responsivo, acessível (navegação por teclado, `prefers-reduced-motion`)

## Rodando

Abra o `index.html` no navegador, ou publique a pasta no GitHub Pages.

## Editando

- **Textos em português**: direto no `index.html`.
- **Textos em inglês**: objeto `EN` no início do `script.js` (mesma chave do atributo `data-i18n`).
- **Cores**: variáveis no topo do `style.css`.
- **Foto**: troque o bloco `.monograma` no `index.html` por `<img src="foto.jpg" alt="...">`.
